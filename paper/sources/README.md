# Source Manifest

This directory caches papers and web references used to revise `leanflow_paper.tex`.
For each PDF source, the companion `.txt`, `.pdfinfo.txt`, and `.images.txt` files were generated with `pdftotext -layout`, `pdfinfo`, and `pdfimages -list`.

## Document-Scale And Autoformalization

- `wang2026_m2f.pdf`: M2F, the main document-scale comparison.
- `wu2022_autoformalization.pdf`: early LLM autoformalization baseline.
- `azerbayev2023_proofnet.pdf`: ProofNet, undergraduate-level NL/formal statement/proof benchmark.
- `lu2024_process_autoformalization.pdf`: process-driven Lean 4 autoformalization.
- `poiroux2025_reliable_statement_autoformalization.pdf`: reliable statement-autoformalization evaluation and RLM25/ProofNet# context.
- `poiroux2025_rlmeval.pdf`: RLMEval research-level Lean statement/proof benchmark.

## Lean Tools And Infrastructure

- `demoura2021_lean4.pdf`: Lean 4 theorem prover and language.
- `mathlib2020.pdf`: Lean mathematical library.
- `yang2023_leandojo.pdf`: LeanDojo retrieval and interaction benchmark/tooling.
- `asher2025_leanexplore.pdf`: LeanExplore declaration search.
- `leanprobe2026.html`: LeanProbe repository snapshot.
- `leaninteract2025.html`: LeanInteract repository snapshot.
